Paragraph Anchors: Stable Comment Targets

How we generate resilient paragraph anchors so inline comments survive edits.

Why anchors matter

Each paragraph gets a stable anchor (`p-`) so comments remain tied to the same logical block even if Markdown shifts. Anchors survive minor edits and tolerate reordered sections.

Algorithm overview

We parse Markdown into blocks, normalize text, hash it with pageLocale id, and preserve anchors with a ±3 position tolerance. Orphaned anchors remain for 30 days so existing comments still resolve.

anchorHash = SHA-256(pageLocaleId + ":" + normalizedText).substring(0, 16)
anchorId = "p-" + anchorHash

Edge cases

  • Duplicate content gets unique anchors via position index.
  • Splits keep the first half anchored; merges preserve the first anchor.
  • Reordering uses position tolerance and similarity before issuing new ids.
