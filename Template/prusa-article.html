Release: help-v1.5 Reading time: 7 min

How to update firmware (CORE One L, CORE One, MK4/S, MK3.9/S, MK3.5/S, XL)

Step-by-step guide to keep Original Prusa printers on the latest firmware via offline USB, OTA, or after a factory reset.

Offline USB Drive procedure

Use this when Wi‑Fi is unavailable or you want a clean, air‑gapped update. Download the correct firmware for your model and copy the `.bbf` file to a USB drive.

  1. Download the latest firmware from Prusa’s site (e.g., MK4 support page).
  2. Copy the firmware file (e.g., `MK4_firmware_6.4.0.bbf`) to the root of a FAT32 USB drive.
  3. Insert the USB drive into the printer, navigate to Settings → Firmware Update → USB.
  4. Select the file and confirm. The printer will flash the update and prompt for a restart.

OTA (Over‑The‑Air) firmware update

When Wi‑Fi is configured, fetch and install the newest firmware directly from the printer UI.

  • Connect the printer to Wi‑Fi, then open Settings → Firmware Update → Network.
  • Check for updates; the latest version and changelog are shown inline.
  • Tap Download, then Install. The device reboots automatically when finished.

Factory Reset

After a hard factory reset, you must re‑flash firmware from USB because the internal firmware image is cleared.

Insert a USB drive containing the firmware file, go to Settings → Firmware Update → USB, and install as described above. Repeat Wi‑Fi setup if you want OTA updates going forward.
